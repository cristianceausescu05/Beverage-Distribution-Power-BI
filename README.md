This report visualizes alcoholic beverage distribution in Montgomery County, Maryland from 2017–2020 (data.montgomerycountymd.gov/Community-Recreation/Warehouse-and-Retail-Sales/v76h-r7br/about_data).

![Report Preview]([https://github.com/cristianceausescu05/Beverage-Distribution-Power-BI/blob/a2e661f831ebc867a20d9c73421e4b6739739e89/Report%20image.png)

Key insights:
-	Trends over the years (line or bar chart)
-	Top 5 products and suppliers
-	Number of products and suppliers

Interactive features:
-	Toggle between line and bar chart views
-	Filter by beverage type and sales channel

This project helped me practice data storytelling and building user-friendly dashboards.
